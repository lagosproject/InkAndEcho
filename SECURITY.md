# Security Policy

## Supported Versions

We actively support and patch security issues on the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of **Ink & Echo** seriously. If you find a security vulnerability, please do not open a public issue. Instead, report it responsibly.

### How to Report
Please email your report to **security@lakescorp.com** (replace with your active security address). Include the following details to help us investigate:
* A description of the vulnerability and its potential impact.
* Step-by-step instructions (or a proof-of-concept script/exploit) to reproduce the issue.
* The device, Android OS version, and app version where the issue was observed.

### Our Commitment
We will acknowledge receipt of your report within 48 hours and work to provide a patch or mitigation as quickly as possible. We request that you keep all details confidential until a fix has been officially released.
